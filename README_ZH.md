## 功能特性

### 📱 信息流
无限滚动浏览作品,支持网格或列表视图。登录后可获取来自已关注作者的个性化动态。

### 🔍 搜索
全文与标签搜索,支持自动补全(20 万+ 离线标签)。可按分级、类型、类别、物种、性别、排序方式与日期范围筛选。

### 🖼️ 作品查看
完整作品卡片:图片、作者、数据、标签、简介与评论。可在作品之间滑动,支持双指缩放与平移。

### 👤 个人主页与关注列表
作者主页涵盖图库、收藏夹、正在关注与关注者。一键收藏、一键关注。

### ⬇️ 下载
连同元数据保存图片,集中于下载区管理。

### 🔒 内容筛选
屏蔽标题中的关键词,一键开关成人内容。

### 🎨 个性化
8 套配色主题、8 种应用图标样式、4 种界面语言(EN / RU / UA / 简体中文)、毛玻璃质感 UI。
